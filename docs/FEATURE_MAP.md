# Feature Map – Echo-Boma
## How every major request maps to the 10 segments + cross-cutting systems

This document is the result of word-by-word mapping of the full specification onto a coherent product structure. Culture + Tech studies are integrated into every relevant path.

---


## Detailed Mapping

### 1. User Account
**Contains**
- Bio-profile + interests + culture tags + tech level
- Diary (daily / weekly / monthly / annual) with entry formats & spaces
- Text / voice / video notes (cloud + offline)
- Personal time-boxing of activities
- Strategies & personal implementable policies
- Outcomes review (not just visions)
- Statistical graphs (time spent, progress, probability/feasibility of projects)
- Analyzer suggestions for effective time use & planning
- Badges for impactful contributions
- Invite-a-friend
- Linked reminders

**Integrates culture + tech**  
Diary reflections can be tagged with cultural frameworks or tech skills applied. Progress graphs show both cultural competence and tech skill growth.

### 2. Settings
**Contains**
- User access limits (first-run on → bottom dialog to disable)
- Voice
- Sign language preference
- Real-time subtitles
- Language selection (English, French, Swahili, Arabic + verified local)
- Privacy & data controls
- Notification preferences
- Theme / colour preferences (colourful & motivating)

### 3. Notifications
**Contains**
- Awareness challenges
- Competitions
- Personal / group research updates
- Diary & time-box reminders
- System announcements (filtered for relevance)
- Celebrate small wins
- Meeting / webinar reminders

### 4. Echo Guide
**Contains**
- AI navigation assistant
- Tailored short videos on how to use each segment
- Real-time answers to user questions
- Suggestions based on role & interest
- Explains limits, expectations, guidelines
- Help with becoming impactful

**Does not** control backend or override moderation.

### 5. Real-time Sign Language Video Bar
**Phase 1**  
Curated, high-quality sign language videos for key flows + always-available text alternatives.

**Phase 2**  
Limited real-time sign language support in selected rooms (with user consent and bandwidth awareness).

Always controllable from Settings.

### 6. Pop-up Dialogue Box
Contextual, non-blocking where possible:
- First-run / onboarding
- Consent & privacy
- Confirmations (delete, share, continue research, etc.)
- Quick tips

### 7. Global Society (e-boma)
**Contains**
- Meeting schedules (discuss issues & progress)
- Conflict resolution spaces
- Webinars
- Discussion groups (e.g. weekly tea discussions)
- Cultural experiences sharing
- Brainstorming & Think Hub
- Share success stories, failure stories, lessons learned
- Automatic AI-assisted minutes & summaries (editable, opt-out)
- Peer review of outcomes
- Feedback loops

**Integrates culture + tech**  
Discussion prompts can draw from Sankore / Ubuntu / Kaizen etc. and from tech tools learned in the Virtual School.

### 8. Research
**Contains**
- Interdisciplinary research
- Collaborative research with group badges (all contributor names)
- Peer-reviewing of articles & research
- Find teammates (interest-based; optional entry quiz with time limits, anti-copy-paste, rotating questions)
- Implementation support & partnerships
- Share files from other locations/sites
- Connect research materials to E-zone simulator for visual/animated presentations
- Continue unfinished research only with explicit prior consent
- Commit to research → system helps with planning
- Feasibility testing of projects
- Full record keeping
- Multimedia support
- Automatic save of all progress
- Assignment assistance by current group members

**Copyright / IP**  
Clear attribution, license selection, contribution tracking.

### 9. E-zone
**Contains**
- Simulations (research, sketches, text → game-format communication)
- Improved / animated presentations
- Virtual schools & labs
- Environment-based learning
- Physical / academic / moral education content
- Gamification (video + text)
- Music & moral educational videos
- Automatic updates based on searches & interests
- Imagination & critical thinking support

**Directly hosts** the Virtual School (Culture Lab + Tech Lab + Fusion Lab) from earlier blueprints.

### 10. Home Tab
**Contains**
- Dashboard overview
- Awareness challenges
- Competitions
- Shortcuts to personal & group research
- Feeds (create / view / modify / delete videos, text, voice)
- Challenges board
- Success / failure stories
- Hot take of the week
- Bin (recoverable deletions)
- Global Search entry point

## Cross-Cutting Systems (Must Be Present)

| System | Purpose | Notes |
|--------|---------|-------|
| Cloud saving + local cache | Real-time progress never lost | Offline-first design |
| Verification & validation | Data integrity | On every write path |
| Content filters | Deter inappropriate posts | AI + human review |
| Telemetry & traffic management | Security foundations | Rate limits, anomaly detection |
| Automatic save & update | Every segment | User never loses work |
| Indexing & sorting | Neat organisation | Fast retrieval |
| Smart search | Narrows to relevant results | Text + voice + scan + camera |
| Interest-based grouping | Personalisation | Respects privacy |
| Celebrate small wins | Motivation | Micro-interactions + notifications |
| Bluetooth / local sharing | Offline equity | Pack sharing for schools/rural |
| Dynamic backend | Maintenance & modification | Feature flags + content packs |

## Main Learning Fields (Interdisciplinary)

- Science & Technology
- Life Sciences
- Culture & Traditions (especially impact on life sciences)
- History (learning from societal pasts)
- Medical Research
- Liberal Arts

**Focus**: Start at the personal level to improve practices and policies; avoid pure blame of policy makers.

## Feeds & Social Layer (Home + e-boma)

Users can create, modify, delete, share:
- Videos (with navigation / scrolling)
- Text
- Voice recordings
- Files from other sites/locations

Cache viewed feeds; refresh when online.  
Blogs / POVs on fields.  
Success stories (what worked), failure stories (what to avoid), research on societal problems.

## Feedback Tab

Users send feedback → Backend analyses → Provides recommendations → Decision support for improvements.
